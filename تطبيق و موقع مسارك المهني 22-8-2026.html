LinkedIn — OAuth + مشاركة الشهادات

developer.linkedin.com

تسجيل الدخول بحساب LinkedIn واستيراد مهارات المستخدم، ثم مشاركة شهادات مسارك تلقائياً على الملف المهني.

  1. 1سجّل في بوابة مطوري LinkedIn وأنشئ تطبيقاً جديداً
  2. 2احصل على Client ID و Client Secret
  3. 3فعّل منتجي "Sign In with LinkedIn" و "Share on LinkedIn"
  4. 4أضف روابط التحويل (Redirect URLs) الخاصة بمسارك
بوابة المطورين
مقتطف كود تقني (للمطورين) 
// LinkedIn OAuth 2.0
const url = 'https://www.linkedin.com/oauth/v2/authorization'
  + '?response_type=code'
  + '&client_id=' + CLIENT_ID
  + '&redirect_uri=' + REDIRECT_URI
  + '&scope=r_liteprofile%20r_emailaddress';
window.open(url, '_blank');

Coursera — برنامج الشراكة + API

affiliates.coursera.com

عرض كورسات Coursera داخل مسارك مع عمولة 10-20% على كل اشتراك، وربط الشهادات بحساب المتعلم.

  1. 1انضم لبرنامج Coursera Affiliate أو Coursera for Campus
  2. 2احصل على صلاحية الوصول لـ Courses API
  3. 3استورد الكورسات واربطها بمسارات مسارك
  4. 4استخدم Deep Links لفتح الكورس في تطبيق Coursera مباشرة
برنامج الشراكة
مقتطف كود تقني (للمطورين) 
// Coursera Courses API
fetch('https://api.coursera.org/api/courses.v1'
  + '?q=search&query=' + skill,
  { headers: { 'Authorization': 'Bearer ' + API_KEY } })
  .then(r => r.json());

Udemy — Affiliate API

udemy.com/affiliate

ابحث في مكتبة Udemy الضخمة واعرض أفضل الكورسات لكل درس — بعمولة تصل إلى 15% عبر روابط الإحالة.

  1. 1سجّل في برنامج Udemy Affiliate
  2. 2احصل على بيانات الاعتماد (Client ID + Secret)
  3. 3ابحث عبر Courses API واعرض التقييمات والمراجعات
  4. 4ولّد روابط إحالة بمعرّف مسارك لتتبع الأرباح
برنامج الشراكة
مقتطف كود تقني (للمطورين) 
// Udemy Affiliate API
const cred = btoa(CLIENT_ID + ':' + CLIENT_SECRET);
fetch('https://www.udemy.com/api-2.0/courses/'
  + '?search=' + topic + '&page_size=10',
  { headers: { 'Authorization': 'Basic ' + cred,
               'Accept': 'application/json' } })
  .then(r => r.json());

Indeed — Publisher API

developer.indeed.com

اعرض أحدث الوظائف المطابقة لمهارات كل متعلم داخل مسارك مباشرة — بتغذية حية من Indeed.

  1. 1سجّل كـ Publisher في بوابة مطوري Indeed
  2. 2احصل على Publisher ID الخاص بك
  3. 3استعلم عن الوظائف بالكلمات المفتاحية والموقع
  4. 4اعرض النتائج مرتبة بالتاريخ داخل تبويب الوظائف
بوابة المطورين
مقتطف كود تقني (للمطورين) 
// Indeed Job Search API
fetch('https://api.indeed.com/ads/apisearch'
  + '?publisher=' + PUBLISHER_ID
  + '&q=' + query + '&l=' + location
  + '&sort=date&limit=10&format=json')
  .then(r => r.json());
